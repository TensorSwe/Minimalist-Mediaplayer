# Minimalist-Mediaplayer

# About:
A high-res mediaplayer inspired by the "TP-7" made by "Teenage Engineering".

**Project link:** https://stardance.hackclub.com/projects/59501

# Parts:
* **1x Raspberry Pi PICO 2**
* **1x Electro:kit EKM001 charger board**
* **1x Adafruit UDA1334A Stereo DAC I2S breakout board**
* **1x iFlight GBM2804H-100T Gimbal Motor**
* **1x SparkFun Brushless Motor Driver TMC6300**
* **1x EastRising ER-OLED1.09-2W**
* **1x EastRising ER-OLED1.29-1W**
* **1x Akyga AKY2465 Li-Ion 18650 3.7V battery**
* **1x Electrokit EKA-USB-C 6-pin breakout board**
